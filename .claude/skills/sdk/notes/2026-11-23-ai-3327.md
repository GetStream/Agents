Every SDK names itself and its release on each request, so the router's request log and its activity count can tell which SDK, and which release, made a call (AI-3327). Go sets `User-Agent: stream-agents-go/<Version>` beside `X-Stream-Client: sdk` in `Backend.Credentials()` (`sdks/go/stream/backend.go`), with `Version` a literal bumped at each release, never read from build info (a branch build reads `(devel)`). JavaScript sends `X-Stream-Client: sdk` from `Backend.headers()`, and from Node also `User-Agent: stream-agents-js/<VERSION>`; a page sends `X-Stream-Client` alone, since neither the router's nor the proxy's CORS list allows `User-Agent`. The router needs no change: it logs `user_agent` and `x_stream_client` on every request and counts `X-Stream-Client: sdk` under client `sdk`. Other SDKs need to update: Python (`plugins/stream`) sends `X-Stream-Client: sdk` with no `User-Agent` of its own; .NET, Ruby, Rust, PHP, Swift, Kotlin and Dart send neither yet. Each sends `stream-agents-<language>/<version>` from a literal version constant, and only a server-side SDK or one off the browser sets `User-Agent`.
