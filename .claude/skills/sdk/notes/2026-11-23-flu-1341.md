Dart takes a live UI patch's base as Kotlin does (#2089, #2199, no wire change): `Conversation._writeUI` merges an OpenUI patch onto the latest earlier agent turn whose UI is complete, non-empty and not interrupted (`_cut`), in any format; a base that isn't OpenUI, or none, leaves the turn no `Turn.ui`, and `LiveUI.observe` drops it. Like Kotlin, it differs from the router (`conversation.go` `finish`, `chatlog.go` `settle`): the base is picked by position and on `ui_completed`, not by the turn the router last finished, and a patch stored as written is not the next base. Other SDKs need to update: Swift (`Conversation.swift` `writeUI`) and JavaScript (`conversation.ts` `resolveUIContent`) still merge onto the latest OpenUI card of any turn. Dart should cut off a turn an error ends once it ends one (FLU-1341).
