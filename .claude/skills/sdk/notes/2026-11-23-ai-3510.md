`listActivity` is Stream staff's (AI-3510): `GET /v1/ops/activity?from=&to=&limit=&cursor=` with the ops key, answering `ActivityPage` (`items` of `ActivityDay`, `organizations` of `OrganizationProgress`, `has_more`, `next_cursor`). Go, JavaScript, Python, .NET and PHP gain its generated schemas, Ruby and Rust the operation too, as for `getOrganizationActivity`. No SDK wraps it, so nothing else needs to change. Swift, Kotlin and Dart generate only client-accessible operations and need nothing.
