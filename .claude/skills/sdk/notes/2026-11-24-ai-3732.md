An agent folder loads only the files inside it (AI-3732). Go (`sdks/go/agents/folder.go`) and Python (`plugins/stream/.../folder.py`) resolve the agent directory to an absolute real path once, then refuse any file read whose real path is outside it, with an error that says the path "links outside the agent directory". That covers `agent.yaml`, `instructions.md`, `guardrail.md`, every file under `skills/` (`*.md`, a folder's `SKILL.md` and its other files), `knowledge/` itself and every document under it, `knowledge/urls.yaml`, and every file under `simulations/`. A link that stays inside the directory is still read, and an agent directory reached through a link, or named relative to the working directory, still loads. Knowledge now leaves out hidden files and folders (`.draft.md`, `.git/`), as skill folders already did. Other SDKs need to update: a folder loader resolves the agent directory and each path it reads to an absolute real path, refuses one outside the directory, and skips hidden entries in knowledge.
