`ConnectionInvocation.error_message` (`GET /v1/agents/connections/{id}/invocations`) no longer carries the provider's error body or the call's error (AI-3764). A call the router held itself keeps the router's words, such as `declined by the person` or `rate limited by the router: retry after 30s`; any other failure is `the call failed: <error_type>`, and what the provider answered is only in the router's log under the call's id. Only the field's description changed in the spec. Go, Python, JavaScript, .NET, PHP and Rust have it through their regenerated models, in the same PR. Other SDKs need to update: Ruby takes the new description when it regenerates. Swift, Kotlin and Dart have no invocations operation, which is server-side only.
