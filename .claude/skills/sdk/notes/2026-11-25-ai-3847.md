A dispatch worker's frame over 5 MiB is dropped rather than read (no spec change): the router answers it on the dispatch socket with `{"type": "error", "error", "code": "payload_too_large", "error_type": "payload_too_large"}`, fails the hosted call whose `tool_result` it was, and keeps the worker. The router finds that call by the `id` or `tool_call_id` written before `output`, so a worker keeps writing them in that order. Go's `Dispatch` logs the `error` frame as a warning. Other SDKs need to update: JavaScript, Python (`plugins/stream`), .NET, Ruby, Rust and PHP ignore the frame, and log it as Go does. Swift, Kotlin and Dart have no dispatch worker.
