JavaScript's folder loader reads `agent.yaml`'s `greeting` as Go's does, settling its part of the «`agent.yaml`'s `greeting` may be its text alone» note in `../SKILL.md`. `greeting: Hello, how can I help?` is read as `{text, mode: variation}`, a mapping without `mode` is sent with `mode: variation`, and a mapping's own `mode: exact` is kept (`greeting()` and its caller in `sdks/js/src/folder.ts`). A greeting written as a list is refused, as Go refuses one. A greeting built in code (`Agent`'s `greeting`) is unchanged: one with no mode is sent with none, which the API reads as `exact`. A folder synced before now has a different fingerprint, so its next sync sends it once. Python (`plugins/stream` `folder.py`, `_greeting`), .NET, Ruby, Rust and PHP still owe theirs.
