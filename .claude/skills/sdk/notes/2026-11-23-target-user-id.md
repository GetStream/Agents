An incognito session's tool call waiting for approval is shown as an `ai_tool_call` step with `target_user_id`: the user Stream's approver shows the card to. Kotlin and Dart send the person's user, the one the app signed in as (`backend.user` in Kotlin, `backend.userId` in Dart), which is what a kept reply's step uses (the conversation's owner, `parts.go`). `Session.user_id` is the name the agent joined the call as, not the session's owner. Other SDKs need to update: Swift (`TurnMessage.swift`) and JavaScript (`turn-messages.ts`) should send the person's user as `target_user_id`, as Kotlin and Dart do, not `Session.userId`. The server SDKs need nothing.
