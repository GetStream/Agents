A session's `project_id` is the `project` cost tag only when a backend sends it, on createSession, forkSession and the session socket (AI-3728). An end user's device may still send one: it groups and filters the session and tags no usage. Nothing is refused and no type changed. Go's comments on `ProjectID` (`sdks/go/client/sessions.go`, `sdks/go/agents/agent.go`, `sdks/go/stream/accelerated.go`) say so. Other SDKs need to update: the same comment, which Python (`plugins/stream/.../sessions.py`) and .NET (`Agent.cs`) still have as "carried as a cost label too".
