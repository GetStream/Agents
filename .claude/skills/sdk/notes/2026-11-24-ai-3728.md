A session's `project_id` is the `project` cost tag only when a backend sends it, on createSession, forkSession and the session socket (AI-3728). An end user's device may still send one: it groups and filters the session and tags no usage. No type changed. A project longer than a tag (256 bytes) is a 400 as before, now also beside an explicit `project` tag and on any fork. Go's comments on `ProjectID` (`sdks/go/client/sessions.go`, `sdks/go/agents/agent.go`, `sdks/go/stream/accelerated.go`) say so. Other SDKs need to update: the same comment, which Python (`plugins/stream/.../sessions.py`) and .NET (`Agent.cs`) still have as "carried as a cost label too", and Dart (`stream_agents/lib/src/core/models.dart`) and Kotlin (`core/.../Options.kt`), whose `projectId` says it is also its "project" cost tag: a device names none, so it only groups sessions.
