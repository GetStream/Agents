The default URL is `https://accelerate.gcp.stream-io-api.com`, a load-balanced hostname that sends each request to the nearest healthy live production region (AI-3695). `https://accelerate-<region>.gcp.stream-io-api.com` stays what a region pins to, and `region_url`/`RegionURL` is unchanged. Go sets it in `DefaultURL` in `sdks/go/stream/backend.go`, and its `hosted()` check, which decides that a URL is behind the proxy and so always authenticates, now also accepts the default, since it has no `-<region>` suffix. Without that, a backend with a customer id set stops sending its credential to the default router. Other SDKs need to update the default constant, the hosted check where there is one, and the tests that assert either:

- JavaScript: `DEFAULT_URL` and `hosted()` in `sdks/js/src/backend.ts`.
- Python (`plugins/stream`): `DEFAULT_URL` and `_hosted()` in `vision_agents/plugins/stream/_backend.py`.
- Swift: `Backend.defaultURL` in `sdks/swift/core/Sources/StreamAgents/Backend.swift`.
- Kotlin: `DEFAULT_URL` in `sdks/kotlin/core/src/main/kotlin/io/getstream/agents/android/core/Backend.kt`.
- Dart: `defaultUrl` in `sdks/dart/stream_agents/lib/src/core/backend.dart`.
- .NET: `DefaultUrl` and `Hosted()` in `sdks/dotnet/src/GetStream.VisionAgents/Backend.cs`.
- Ruby: `DEFAULT_URL` and `hosted?` in `sdks/ruby/lib/getstream/vision_agents/backend.rb`.
- Rust: `DEFAULT_URL` and `hosted()` in `sdks/rust/src/backend.rs`.
- PHP: `DEFAULT_URL` and `hosted()` in `sdks/php/src/Backend.php`.
