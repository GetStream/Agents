`GET /v1/stats/spend` rows carry `other` (AI-3511): true on the row that sums every value outside the biggest few, whose `value` is still `"other"`, and left out on every other row. A cost label whose value is `"other"` is now a row of its own, no longer merged into the remainder. Go (`sdks/go/acceleration/generated.go`), Python (`plugins/stream` `_generated`) and JavaScript (`sdks/js/src/generated/api.ts`) are regenerated. Other SDKs that model `SpendBucket` by hand need the optional boolean, and any code that picks the remainder by `value == "other"` should read `other` instead.
