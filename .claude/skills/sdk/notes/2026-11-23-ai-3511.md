`GET /v1/stats/spend` rows carry `other` (AI-3511): true on the row that sums every value outside the biggest few, whose `value` is still `"other"`, and left out on every other row. A cost label whose value is `"other"` is now a row of its own, no longer merged into the remainder. The field is optional, so a client reading an older router still parses its rows. Seven SDKs are regenerated in the same change: Go (`sdks/go/acceleration/generated.go`), Python (`plugins/stream` `_generated`), JavaScript (`sdks/js/src/generated/api.ts`), .NET (`sdks/dotnet` `Generated/Models.cs`), PHP (`sdks/php/src/Generated/SpendBucket.php`), Ruby (`sdks/ruby` `generated/spec.rb`) and Rust (`sdks/rust/src/types.rs`). Swift, Kotlin and Dart have no `SpendBucket`, so nothing is owed there. Code that picks the remainder by `value == "other"` should read `other` instead.
