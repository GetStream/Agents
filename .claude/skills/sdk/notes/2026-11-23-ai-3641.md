Every SDK names itself and its release in `X-Stream-Client`, in the shape other Stream SDKs send (stream-chat-js `stream-chat-js-v<version>-<node|browser>`, stream-chat-go `stream-go-client-<version>`), so a browser, which cannot set `User-Agent`, still says which release made a call (AI-3641). Go sends `stream-agents-go-v<Version>` (`ClientSDK` in `sdks/go/stream/backend.go`). JavaScript sends `stream-agents-js-v<VERSION>-node` from Node and `stream-agents-js-v<VERSION>-browser` from a page (`clientHeaders()` in `sdks/js/src/backend.ts`). `User-Agent` stays as AI-3327 set it. The router counts any client that starts with `stream-agents-` (in any case) as `sdk` in the activity record and the audit log, and plain `sdk` still counts as `sdk`. Other SDKs need to update: Python (`plugins/stream`, `CLIENT_HEADER` in `_backend.py`) sends `stream-agents-python-v<version>`; .NET, Ruby, Rust and PHP send `stream-agents-<language>-v<version>`; Swift and Kotlin send `stream-agents-<swift|kotlin>-v<version>`. Each takes the version from the same literal constant as its `User-Agent`. Dart sends `stream-agents-dart-v<version>` on every request (`streamClient` in `sdks/dart/stream_agents/lib/src/core/backend.dart`), from `sdkVersion`, which a test holds to `pubspec.yaml`'s `version`; its sockets carry only a query, so they send none.
