# internal/connectors/sensitive

The rule that keeps a connector whose manifest says `sensitive: true` (its tools read private data) away from what may send data out with no person's approval: a binding to a source that does not say `outbound: false` (unless each tool it grants is in `read_only_tools` or its `require_approval`), a binding with `sandbox` set, and a sandbox that reaches the network.

- `ConfigComplaint` checks one agent config. Config writes call it (`internal/api`: create, update, patch, sync), so a config that breaks it is a 400. A session start calls it on its config's bindings and sandbox (`attachConnectors`, `internal/session/connector_tools.go`) and refuses to open one that breaks it, which covers a config stored before the writes checked it.
- An import (`POST /v1/data/import`, `router replicate`) calls both through `store.SetConfigRule`, which `openStore` (`cmd/router`) sets, since `internal/store` cannot import this package. It weighs each config it writes and each set that config is part of inside the import's transaction: an export row once that row is written, and a page of changes once the whole page is written. A config that breaks the rule refuses the row or the whole page, naming it as `agent_configs:{"id":…}`. An export carries agent configs before connector definitions, so a connector definition the import writes weighs again, in the same transaction, each live config of the app that binds it, and refuses as `connector_definitions:{"id":…,"revision":…}`.
- `GraphComplaint` checks a parent and its child agents as one config. A parent hands its input to each child and reads each answer, so what one reads may reach any other, a sibling's tools included. Config writes call it (`sensitiveGraphComplaint`, `internal/api/child_agents.go`) over the config with its children and over each parent that calls the config with all of that parent's children, so a set that breaks it is a 400 naming the agents, the bindings and the connector, even for a save that changes another field. `childRunner.Run` (`internal/session/child_agents.go`) calls it on every delegation, with the parent as it runs and each child as stored now, and refuses a delegation that breaks it with a tool error the model reads: it covers a set stored before the writes checked it.

It lives here, not in `internal/api`, because `internal/api` imports `internal/session`, and both need it. It reads only the store and the manifest model.

Check: `go test -tags integration -run 'TestChildAgentsSuite/(TestADelegation|TestAWrite|TestASession|TestARun)|TestConfigsSuite/TestNessy|TestDataMoveSuite/(TestAnImported|TestAChangedChild|TestImportedAgents)' ./internal/api` and `go test -tags integration -run 'TestReplicateRepeatSuite/(TestAPage|TestAFirstCopy)' ./cmd/router`.
